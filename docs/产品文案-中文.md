# Roam 界面文案规范(以中文为产品主体语言)

> 产品二稿定稿:国内用户、中文主体。所有用户可见文案一律中文;
> 代码注释/提交信息中文优先;内部标识符与英语技术词(print/Long/Gradle 等)保持英文原始形态。

## 首页

| 场景 | 文案 |
|---|---|
| 首启标题 | 你的回忆,早已在手机里。 |
| 首启说明 | Roam 只读取照片的时间和位置信息(不上传、不看内容),自动发现你走过的旅行。 |
| 首启按钮 | 授权照片访问 |
| 扫描中 | 正在扫描你的回忆… · 只读取时间与位置,不上传 |
| 空结果 | 还没有发现旅行。 |
| 有结果 | 发现了 N 次旅行。 |
| 统计行 | NN 张正片 · NN 个待确认 |
| 折叠区标题 | 可能是旅行 (N) |
| 折叠理由 | 单日活动,缺少跨天证据 / 跨天但距常住地太近(疑似本地) / 常住地未设置,无法判断远近 |

## Trip 卡片

- 副标题:`yyyy年M月d日 — yyyy年M月d日`
- 统计:`NN 张照片 · 置信度 NN%`
- 标题默认值:`还未命名的旅行`

## 术语对照(功能语境下的对外词)

- Trip → 旅行(技术标识符仍用 Trip)
- We found N trips → 发现了 N 次旅行(不再保留英文标语)
- On This Day → 多年前的今天
- Travel Timeline → 时间线
- Place → 地点
